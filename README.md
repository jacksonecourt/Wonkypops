# Wonkypops

Launch website for Wonkypops, Australian icy poles made from rescued, imperfect fruit. Rescued fruit. Real good.

- `site/` : the website (Next.js + TypeScript + Tailwind). See `site/README.md` to run it and edit content.
- `assets/` : logo and mascot files.
- `CLAUDE.md` : the project brief (brand, content rules, sitemap, feature specs).
